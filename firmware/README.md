# Firmware

The Arduino IDE sketch lives in [`SelfBalancingRobot/`](SelfBalancingRobot/). Open
`SelfBalancingRobot.ino` and press upload.

Full instructions, the file-by-file breakdown and the serial protocol are in
[`docs/firmware.md`](../docs/firmware.md). Start with
[`SelfBalancingRobot/Config.h`](SelfBalancingRobot/Config.h): it holds every number you are
likely to want to change, each with a comment saying what it does.

Board: **Arduino Mega or Mega 2560**, processor **ATmega2560**. No external libraries are
needed.
